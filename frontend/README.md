# SANKET AI Frontend

Next.js + React + TypeScript + Tailwind UI for SANKET AI.

## Routes
- `/` home
- `/live` live camera + websocket status
- `/video` video analysis scope
- `/history` session history placeholder
- `/about` scope and honesty notes

## Run
```bash
cp .env.example .env.local
npm install
npm run dev
```

## Checks
```bash
npm run lint
npm run test
npm run build
```
